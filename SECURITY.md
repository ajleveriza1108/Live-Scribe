# Live Scribe security and privacy
Live Scribe is designed for local transcription and local storage.

## Reporting a vulnerability
Do not publish recordings, transcripts, resumes, interview profiles, license material, private logs, or sensitive details in a public issue. Contact the repository owner privately with a sanitized report.

## Repository privacy rules
The source repository must not contain machine-specific hardware reports, first-run markers, user settings, interview profiles, recordings, exports, downloaded models, caches, or session databases.

Run before publication:
```text
python scripts/repository_preflight.py
```
