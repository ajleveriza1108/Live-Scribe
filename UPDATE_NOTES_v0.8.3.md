# Live Scribe v0.8.3

## Selected microphone listening

- Added Listen to this microphone, off by default.
- Added a selectable playback output.
- The switch and output can change during live transcription.
- Monitoring runs in a separate bounded playback worker.
- Raw transcription input and WAV recording remain unchanged.
- Enabling the option while idle starts the no-recording input preview.
- Added headphone/feedback guidance.
- Unavailable playback devices remain visible but disabled.
